## 🗺️ Clear Multi-Page Site Map & Architecture

Instead of dumping everything onto a single heavy page, TomorrowLand is architected into **7 dedicated, editorial, visual-first pages** following the design philosophy of **[Apricus Cafe](https://www.apricuscafe.com/)**:

| Route | Page Name | Primary Strategic Goal | Key Visual & Functional Elements |
|---|---|---|---|
| `/` | **Home** | Brand desire & day-to-night curiosity | Atmospheric Hero with Day/Night mood toggle, 4.6★ social proof banner, Signature dish teasers, 2,660 sq. ft. preview |
| `/menu` | **Digital Menu** | High-volume ordering & zero wait times | Categorized dishes with NPR pricing (`Rs.`), dietary pills (Veg/Spicy/Crowd Favorite), live search, and sticky WhatsApp Pre-Order tray |
| `/the-space` | **The Space & Story** | Architectural authority & spatial familiarity | Vivid Interiors architectural story, 2,660 sq. ft. multi-zone spatial guide, interactive seating explorer, authentic photo gallery |
| `/events` | **Live Gigs & Arena** | Drive repeat weekend traffic | Friday Acoustic Unplugged, Saturday DJ Pulse, Live Cricket/Football match projections, direct table reservation hooks |
| `/reviews` | **Verified Reviews** | Overwhelming social proof & local trust | 4.6★ score breakdown from 278+ Google reviews & 5/5 Facebook rating, keyword filters (*Jhol Momo*, *Pizza*, *Ambience*, *Live Music*) |
| `/careers` | **Join The Crew** | Attract culinary, barista & service talent | 5 published live vacancies (Barista, Wok Chef, Mixologist, Host, Social Media Creator), culture & perks, 1-click WhatsApp application |
| `/contact` | **Locations & Reserve** | Direct bookings & navigation | Side-by-side cards for Kawasoti Main Hub & Riverside Tomorrowland, embedded Table Reservation form, hotlines (`+977 9806919349`), FAQ |

## ⚡ Direct Conversion Pathways

- **Pathway A (Instant WhatsApp Pre-Order):** Built for students and highway commuters on tight schedules. 1-click order generator routes directly to frontline WhatsApp (`+977 9806919349`) with pre-filled items, prep-time estimate (15–20 mins), and customer name.
- **Pathway B (Venue Event Booking & Table RSVP):** Instant booking engine for birthdays (with custom song requests as praised in reviews!), match nights, and family dinners.

## 🛠️ Tech Stack & Hosting

- **Framework:** React 18 + Vite 5 + TypeScript + React Router v6
- **Styling:** Tailwind CSS with custom neon palettes, Cormorant Garamond, Cinzel, and Plus Jakarta Sans typography
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti
- **Hosting:** Fully optimized for **Vercel** with client-side SPA routing (`vercel.json`)

## 🚀 Deployment Instructions

### Deploy to Vercel via GitHub:
```bash
git remote add origin <YOUR_GITHUB_REPO_URL>
git push -u origin main
```
Import the repository on [vercel.com/new](https://vercel.com/new). Vercel will automatically detect Vite and deploy.

### Local Development:
```bash
npm install
npm run dev      # Runs dev server at http://localhost:5173/
npm run build    # Generates optimized dist/ production bundle in ~1s
npm run preview  # Previews production build locally
```
